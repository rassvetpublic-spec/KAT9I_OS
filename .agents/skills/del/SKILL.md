# Скилл безопасного удаления чата (/del)

Этот скилл запускается по команде `/del` и гарантирует, что ни одна строчка ценного кода или важная идея не пропадет при удалении окна.

## Алгоритм работы (Строгий порядок)

### Шаг 1. Первичный аудит и обновление индексов
1. **Обновить каталог скриптов**: Если в репозитории существует файл `scripts/generate_catalog.py`, запустить его (`python scripts/generate_catalog.py`), чтобы гарантировать, что все новые скрипты попали в `CATALOG.md` (в том числе в раздел "Проверить новое").
2. Внимательно проанализировать всю историю текущего чата (transcript).
3. Найти все фрагменты кода, "супер-идеи", решения и задачи, которые еще не были сохранены на диск, не отправлены в CKS или не оформлены как Issue.
4. Сформировать JSON-объекты `distillate_object_v1` для всех важных находок.

### Шаг 2. Интерактивная пауза (Использование ask_question)
1. Вывести пользователю список найденных неоформленных идей.
2. Проактивно предложить завести на них GitHub Issues, **СТРОГО ИСПОЛЬЗУЯ инструмент `ask_question`** (с кнопками вариантов ответа, а не просто текстом). В вариантах обязательно предусмотреть выбор целевого репозитория (по протоколу #224) или отказ.
3. Дождаться выбора пользователя через UI-форму.

### Шаг 3. Вторичная верификация
1. Обработать выбор из `ask_question` (создать Issues или пропустить).
2. Рассчитать метрику потерь (Loss Threshold): процент ценной информации, которая исчезнет при удалении чата. 

### Шаг 4. Оформление Дайджеста (Чат + Внешний файл)
Важно: Артефакты внутри чата удаляются вместе с чатом! Поэтому финальный дайджест нужно **ОБЯЗАТЕЛЬНО вывести прямо в чат красивым текстом**, а копию сохранить во внешний файл: `C:\GIT\KAT9I_OS\История\delete_audit_<id>.md`.

1. **Дайджест сохранения**
   Markdown-таблица с четкими абсолютными путями (где лежат файлы скриптов) и URL-ссылками на созданные Issues.
2. **Список потерь**
   Краткое перечисление того, что будет безвозвратно удалено.
3. **Визуализация (Текстовый прогресс-бар)**
   В самом низу выведите красивый текстовый прогресс-бар:
   `Сохранность: [███████████████████░] 98%`
4. **Финальная плашка**
   Если процент потерь < 5%, вывести стандартный алерт (только `[!TIP]` или `[!NOTE]`, так как `[!SUCCESS]` не поддерживается GitHub Markdown):
   > [!TIP]
   > **Удаляй этот чат — безопасно сохранено в:**
   > - <перечисление путей к скриптам>
   > - <ссылки на Issues и CKS>
