# KAT9I_OS

**Персональная агентная операционная система.**

Если вы впервые открыли этот репозиторий, начните не с технического задания целиком, а с одного из пяти маршрутов ниже.

## 🚀 Я здесь впервые (быстрый старт за 8 шагов)

Откройте [Режим «Я здесь впервые»](docs/guides/FIRST_TIME_GUIDE.md) — краткий пошаговый маршрут от сути системы до первой безопасной задачи.

## Я хочу понять, что это такое

KAT9I_OS принимает задачу, применяет правила, находит нужный контекст, выбирает подходящий способ выполнения, назначает исполнителя, контролирует работу, проверяет результат и учится на фактических данных.

Каноническая архитектурная документация находится в [`docs/`](docs/).

## Я хочу научиться работать с проектом

Откройте [GitHub для коворкеров KAT9I_OS — с нуля на примере проекта](docs/guides/GITHUB_FOR_COWORKERS.md).

Там простыми словами объяснены:

- Issue (задача);
- ветка;
- commit (сохранённый шаг);
- PR (запрос изменений);
- QA (независимая проверка);
- merge (принятие изменений);
- этапы и официальные выпуски.

## Я хочу задать вопрос, предложить идею или сообщить об ошибке

Используйте [русскую форму обратной связи](https://github.com/rassvetpublic-spec/KAT9I_OS/issues/new?template=feedback.yml).

Не нужно самостоятельно знать приоритет, Domain (предметную область) или название внутреннего модуля. Опишите ситуацию обычными словами.

## Я хочу взять задачу и помочь

Откройте [Issues — список задач](https://github.com/rassvetpublic-spec/KAT9I_OS/issues).

Перед началом работы проверьте Scope (область разрешённых изменений) и не расширяйте задачу молча.

## Где источник истины

Для каждой сущности используется одно каноническое место:

- `docs/` — принятая архитектура и спецификации;
- Issues — состояние работы;
- GitHub Actions — Evidence (доказательства автоматических проверок);
- Releases — официально выпущенные версии;
- Projects и HTML — только удобные представления, а не отдельная истина.

Подробная политика: [GitHub — ведение проекта и совместная разработка KAT9I_OS](docs/spec/24_GITHUB_PROJECT_MANAGEMENT.md).

## Инструменты кастомизации Antigravity Standalone

Для настольного приложения Electron (Antigravity Standalone) реализован набор инструментов интерфейса:
- Кастомное контекстное меню по правой кнопке мыши (буфер обмена, перенос текста в чат, вызов скилов);
- Визуальный эффект матрицы (Digital Rain, аккумуляция символов у поля ввода, жидкое стекание по боковым кромкам);
- Руководство по установке и настройке: [tools/antigravity-ui-customization/README.md](tools/antigravity-ui-customization/README.md).
