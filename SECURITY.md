# Политика безопасности репозитория KAT9I_OS

## 1. Сообщение об уязвимостях и проблемах безопасности

Если вы обнаружили потенциальную уязвимость безопасности или утечку чувствительных данных в проекте KAT9I_OS, пожалуйста, **не создавайте публичный Issue**.

Используйте приватное сообщение владельцу репозитория:
- GitHub Security Advisories: [Сообщить об уязвимости](https://github.com/rassvetpublic-spec/KAT9I_OS/security/advisories/new);
- Email: указан в профиле организации `@rassvetpublic-spec`.

## 3. Базовые инварианты безопасности (Fail-Closed)

В соответствии со спецификацией `docs/architecture/04_RULES_AND_EXECUTION_PRIORITIES.md`:
1. **Приоритет безопасности:** `PRIVACY > SECURITY > DATA_INTEGRITY > KNOWLEDGE > AUTO-SYNC`.
2. **Zero Leak:** Никакие токены, приватные ключи, секреты и пароли не должны публиковаться в открытый репозиторий.
3. **Разграничение CONTROL / DATA:** Недоверенные внешние данные (DATA) не могут менять правила выполнения (CONTROL).
