# WORKER_CAPABILITIES

## Принцип

Worker получает только необходимые права.

По умолчанию:

DENY BY DEFAULT

## Минимальные роли

### QA Worker

Можно:
- проверять;
- запускать тесты;
- создавать Evidence.

Нельзя:
- менять код;
- менять Project.

### Sync Worker

Можно:
- выполнять разрешённый sync.

Нельзя:
- менять правила.

### Classification Worker

Можно:
- работать с классификацией.

Нельзя:
- менять lifecycle.

## Расширение

Новые возможности добавляются только через отдельное решение.
