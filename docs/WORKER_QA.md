# WORKER_QA

## Роль

QA Worker проверяет изменения и подтверждает их качество.
Он не исправляет код и не меняет состояние проекта.

## Перед проверкой

Проверить:

- PR и Issue;
- точный commit SHA;
- base branch;
- соответствие задачи изменению.

Если commit изменился во время проверки — статус BLOCKED.

## Проверки

QA Worker выполняет:

1. Проверку изменений.
2. Запуск доступных тестов.
3. Проверку workflow.
4. Проверку требований задачи.
5. Проверку отсутствия запрещённых изменений.

## Запрещено

QA Worker не может:

- менять код;
- менять Project карточки;
- менять классификацию;
- обходить QUEUE-GUARD.

## Результат

Вернуть:

PASS / FAIL / BLOCKED

с указанием:

- commit SHA;
- что проверено;
- найденные проблемы;
- краткое Evidence.

## Правило

PASS ставится только при наличии подтверждения.
Нет доказательства — нет PASS.
