# WORKER_SYNC

## Роль

Sync Worker переносит разрешённые изменения состояния.

Он не принимает архитектурные решения и не меняет правила проверки.

## Проверка перед работой

Проверить:

- источник события;
- разрешение QUEUE-GUARD;
- актуальность данных;
- наличие обязательного Evidence.

## Разрешено

- выполнять разрешённый sync;
- обновлять только назначенные поля;
- создавать отчёт результата.

## Запрещено

- менять классификацию без разрешения;
- обходить очередь;
- изменять чужие поля;
- принимать решение QA.

## Результат

Вернуть:

PASS / FAIL / BLOCKED

с указанием:

- объект изменения;
- источник;
- что изменено;
- Evidence.
