# KAT9I_OS — карта единого контекста

## Назначение
Этот документ сохраняет операционные знания проекта KAT9I_OS.

## Главный принцип
GitHub является единым источником истины (SSoT — единый источник истины).
Чат используется для планирования, но знания должны переноситься в репозиторий.

## Модель ролей

- ChatGPT — архитектура, анализ, координация и Controller/Dispatcher.
- WORKER — выполнение ChangeSet.
- AGY (Antigravity) — независимый QA.
- Codex — анализ кода и ревью.
- Человек — владелец `mtd` и финального разрешения.

## Канонический маршрут QA

- `QA_PROTOCOL.md` — единственный CONTROL-протокол Controller ↔ QA Executor.
- `WORKER_QA.md` — единственная корневая точка входа для команды `WORKER QA`, поиска заданий и правил ограничения токенов.
- `config/qa_worker.json` — машиночитаемые настройки опроса и бюджета токенов.
- Issue #171 — аудит/история задачи, не рабочий inbox.

## Правило mtd

Merge разрешается только после `QA PASS`, прохождения всех обязательных проверок и явной свежей команды владельца проекта `mtd` для текущего exact HEAD.
