## 2. Сторожевой пес (Watchdog)
Чтобы я больше никогда случайно не "выпиливал" сам себя без возможности восстановления, запущен невидимый процесс `pwsh` (PID `38364`), который:
1. Каждые 5 минут проверяет доступность порта `8045` (Менеджера).
2. Каждые 5 минут проверяет наличие процесса `language_server` (Агента).
3. Пишет логи в `C:\Antigravity\watchdog.log`.
4. В случае падения — мгновенно автоматически запускает нужные CLI-скрипты на восстановление.
*Кроме того, внутри самого агента заведен cron (schedule tool) для логирования аптайма.*

## 3. Мой трафик направлен в Менеджер!
Я глобально на уровне пользователя (`HKCU:\Environment`) и локально для своего текущего процесса прописал переменные `GEMINI_API_BASE_URL` и ключи менеджера. Теперь мои запросы, как и запросы ваших воркеров, пойдут через локальный прокси на порт `8045`, сберегая ваш личный баланс токенов!
