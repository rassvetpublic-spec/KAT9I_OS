# Политика языка и терминологии KAT9I_OS

## 1. Основной язык

Вся проектная документация KAT9I_OS ведётся на русском языке.

## 2. Заголовки

Названия разделов и ключевых подразделов обязательно формулируются на русском языке.

Английский технический термин допускается рядом в скобках, если это помогает однозначно связать документацию с кодом, стандартом, API или общепринятым названием.

Пример:

- `Контекст (Context)`;
- `Исполнитель (Worker)`;
- `Запрос на внесение изменений (Pull Request / PR)`;
- `Ссылка на результат (ResultRef)`.

Не допускается заголовок, состоящий только из английского термина, если существует понятная русская формулировка.

## 3. Первое употребление термина

При первом существенном употреблении английского технического термина в разделе рядом даётся краткое русское объяснение.

Дальше допускается использовать технический идентификатор без постоянного повторения перевода, если смысл уже определён.

## 4. Технические идентификаторы

Не переводятся, если перевод ухудшает точность или ломает совместимость:

- имена файлов;
- имена каталогов;
- API;
- URI;
- имена классов и контрактов;
- названия протоколов;
- существующие имена репозиториев;
- идентификаторы полей;
- значения статусов.

Но их назначение в документации объясняется по-русски.

## 5. Именование KAT9I

В новой документации и схемах используется только `KAT9I` или `KAT9I_OS`.

Сокращение `KAT` не используется как новое имя системы.

Исключения допускаются только для исторических или внешних технических идентификаторов, которые нельзя переименовать без нарушения ссылок или совместимости.

## 6. Финальный аудит

Перед утверждением сводного ТЗ выполняется сквозная проверка:

- заголовки на русском языке;
- английские термины имеют русское объяснение;
- одинаковые понятия называются одинаково;
- `KAT` не используется вместо `KAT9I`;
- технические идентификаторы не были ошибочно переведены.
