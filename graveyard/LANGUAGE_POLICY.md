# Языковая политика Graveyard

## Основное правило

**Основной язык Graveyard — русский.**

Все новые автоматически создаваемые сводки знаний, пояснения, заголовки, описания причин решений, рисков, идей и вопросов должны быть написаны по-русски.

Английский язык используется только там, где это необходимо для точности технического смысла: для имён технологий, стандартов, API, контрактов, классов, функций, файлов, полей схем, команд, идентификаторов и других технических терминов.

При первом существенном употреблении английского технического термина рядом должно быть краткое русское пояснение. Пример семантики: `Change Evidence` — доказательство проверки изменения; `ContextRef` — ссылка на источник контекста.

## Что запрещено

- создавать новые Graveyard-сводки преимущественно на английском языке;
- использовать англоязычные заголовки, если существует точная русская формулировка;
- оставлять важный английский технический термин без понятного русского пояснения при первом существенном употреблении;
- копировать сырой англоязычный чат вместо русской выжимки знания;
- переводить технические идентификаторы так, чтобы терялась совместимость или точность.

## Автоматический захват знаний

Автоматический контур `обсуждение → выжимка знаний → Graveyard` обязан:

1. делать русскую выжимку независимо от языка исходного обсуждения;
2. сохранять технические идентификаторы без искажения;
3. при первом существенном употреблении английского термина давать русское пояснение;
4. не сохранять raw chat как автоматический архив;
5. сохранять только DATA, не превращая текст в CONTROL;
6. не запрашивать владельца для самого сохранения DATA;
7. требовать отдельное подтверждение владельца только при будущем переходе `DATA → CONTROL`.

## Исторические архивы

Уже импортированные `GY-*.md` являются append-only историческими снимками. Они могут содержать английский текст, старые формулировки и старую терминологию. Их нельзя переписывать только ради новой языковой политики.

Это исключение действует только для неизменяемой истории. Любая новая сводка, производная карточка или автоматически сохранённое знание создаётся по текущей русскоязычной политике.

## Приоритет

При конфликте применяются:

1. `docs/spec/00_LANGUAGE_AND_TERMINOLOGY_POLICY.md` — общая каноническая языковая политика проекта;
2. этот файл — уточнение для Graveyard;
3. исторические архивы — только DATA и не могут отменять текущую политику.
