# Кастомизация интерфейса Antigravity Standalone

Инструмент расширения и кастомизации интерфейса настольного приложения **Antigravity Standalone** (Electron). Добавляет кастомное контекстное меню по правой кнопке мыши с поддержкой буфера обмена, быстрых действий чата, вызова навыков (skills) и интерактивного окна настроек.

---

## Возможности

1. **Контекстное меню по правой кнопке мыши (ПКМ):**
   * **Буфер обмена:** «Копировать» (`Ctrl+C`), «Вставить» (`Ctrl+V`), «Вырезать» (`Ctrl+X`), «Выделить всё» (`Ctrl+A`).
   * Пункты контекстно активны (например, «Копировать» активно при наличии выделенного фрагмента текста).
2. **Действия для ИИ-чата:**
   * **«Вставить в строку чата»:** автоматически переносит выделенный фрагмент текста (из ответа агента или файла) в поле ввода чата.
   * **«Очистить строку чата»:** мгновенно очищает поле ввода.
3. **Быстрый вызов скилов и команд:**
   * Подменю **«⚡ Скилы и команды»** со списком популярных команд (`/interview-me`, `/agy-customizations`, `/antigravity-guide`, `/grill-me`, `/boost`, `/goal`).
   * При клике подставляет команду в строку ввода вместе с выделенным фрагментом текста (например: `/interview-me [выделенный текст]`).
4. **Визуальный конфигуратор («⚙️ Настройки меню»):**
   * Встроенное модальное окно прямо в интерфейсе Antigravity.
   * Позволяет добавлять свои скилы, менять иконки и команды, удалять ненужные и сбрасывать настройки к значениям по умолчанию.
   * Сохраняет пользовательские параметры в `localStorage`.
5. **Инструменты разработчика:**
   * Пункт быстрого вызова Инспектора элементов / DevTools (`F12`).
6. **Безопасность и обратимость:**
   * Автоматическое создание резервной копии `app.asar.bak` перед внесением изменений.
   * Функция полного отката (`restore`) в оригинальное состояние.

```text

├── Antigravity-UI-Customizer.ps1  # Основной PowerShell-раннер

├── context-menu-config.json      # Базовый конфигурационный файл по умолчанию
└── README.md                     # Документация инструмента
```

## Использование

Для работы утилиты необходим установленный **Node.js** (с поддержкой `npx`).

### 1. Проверка текущего состояния
```powershell
.\tools\antigravity-ui-customization\Antigravity-UI-Customizer.ps1 status
```
Выводит путь к найденному `app.asar`, хэши SHA-256 оригинала и бэкапа, а также статус установки патча (`ORIGINAL` или `PATCHED`).

### 2. Установка контекстного меню
> **Рекомендация:** Перед установкой закройте запущенный Antigravity Standalone.

```powershell
.\tools\antigravity-ui-customization\Antigravity-UI-Customizer.ps1 install
```
Скрипт автоматически:
1. Создаст резервную копию `resources\app.asar.bak` (если её ещё нет).
2. Распакует `app.asar`.
3. Внедрит стили и скрипт контекстного меню в `dist/preload.js`.
4. Соберет новый `app.asar` и проверит целостность.

После установки запустите Antigravity — при правом клике мыши в окне появится контекстное меню.

### 3. Откат к оригинальному состоянию
Если вы хотите вернуть интерфейс к первоначальному состоянию:
```powershell
.\tools\antigravity-ui-customization\Antigravity-UI-Customizer.ps1 restore
```
Скрипт восстановит файл `app.asar` из резервной копии `app.asar.bak`.

### 4. Указание нестандартного пути
Если Antigravity установлен в пользовательский каталог, можно передать путь через параметр `-CustomTarget`:
```powershell
.\tools\antigravity-ui-customization\Antigravity-UI-Customizer.ps1 install -CustomTarget "D:\MyApps\Antigravity\resources\app.asar"
```
